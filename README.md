# SAP Labs Food Court – 3D Layout

Interactive 3D layout of the SAP Labs (Whitefield) food court for Diwali event planning.

Open `index.html` (or the GitHub Pages site) in a browser:
- Drag to rotate, scroll to zoom, right-drag to pan
- Camera buttons jump to each area
- **Event plan → + Add pin** marks counters, decor and utilities on the floor (pins save in your own browser)

Layout and sizes are approximate, drawn from walkthrough photos.
